Publishing

This device can publish to the sign. Edits stay on this device until you tap Publish, then the sign updates within about 30 seconds.

Edit from any phone, tablet or computer, then tap Publish to update the sign. Each device needs a GitHub key once, so only you can change the prices. A device already connected to the home bar menu editor is connected here too.

  1. Create a key on GitHub
  2. Under Repository access, choose Only select repositories and pick Ray-Bar.
  3. Under Permissions, add Contents and set it to Read and write.
  4. Tap Generate token, copy it, and paste it here.

The key is saved only in this browser, and it can only change the Ray-Bar repo.

Setting up at a show
  1. Open the sign in Safari, tap Share, then Add to Home Screen. Launch it from that icon and it runs full screen with no browser bars.
  2. Open it once while you have internet. After that it keeps working with no signal and shows the last prices it loaded. It picks up new prices whenever it gets a connection again.
  3. Set Settings > Display & Brightness > Auto-Lock to Never so the screen stays on, and keep the iPad plugged in.
  4. Optional: turn on Settings > Accessibility > Guided Access to lock the iPad to the sign so customers can't leave it.
  5. To change a price mid-show, edit on your phone and tap Publish. You can also press and hold anywhere on the sign, then tap Edit prices.
